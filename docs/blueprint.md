# **App Name**: LeadView

## Core Features:

- Dashboard Overview: Display a summary of lead generation, including total leads and daily lead counts.
- Lead Volume Analysis: Provide a visual representation of lead volume over time, filterable by state and city.
- Period Selection: Allow users to select a specific time period to analyze lead data.
- State and City Filters: Enable users to filter lead data by state and city for granular analysis.
- Trend Identification: Leverage AI to identify and display key trends in lead generation data, such as peak days or locations.
- Anomaly Detection Tool: Use AI to identify and flag unusual patterns or anomalies in lead generation data.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) for a professional and trustworthy feel.
- Background color: Light gray (#ECEFF1) for a clean and modern look.
- Accent color: Teal (#009688) for highlighting important data and interactive elements.
- Body and headline font: 'Inter', a grotesque-style sans-serif for a modern, objective feel.
- Use clear and concise icons to represent different data points and actions.
- Employ a clean and well-organized layout with clear data visualization elements.
- Use subtle animations to enhance user experience and guide attention.
